[F] Search ("local scaling mutual proximity shared nearest neighbor hubness correction algorithm") — 3 concrete named techniques, all "secondary distance" methods that RESCALE the original distance to symmetrize/correct neighbor relations rather than replacing the underlying metric:
  - **Local Scaling (LS)**: rescales each pairwise distance using LOCAL distance context (e.g. each point's own k-th neighbor distance) as the scaling parameter — cheap, only needs per-point local statistics.
  - **Mutual Proximity (MP)**: transforms distances into similarities computed from the SHARED neighborhood of two points, considering ALL pairwise distances in the dataset (not just local) — stronger correction than LS but needs more global information per pair.
  - **Shared Nearest Neighbors (SNN)**: reduces hubness by measuring similarity via how many neighbors two points have in common, not raw distance directly — weaker hubness reduction than LS/MP per the comparison study, but conceptually simplest.
  - Comparative note: both LS and MP show strong hubness reduction on high-dimensional data specifically, and both IMPROVE downstream matching/classification accuracy as a side effect, not just reduce a hubness metric in isolation.
