**What**
`GaussianSplatMorpher` (Runtime) + `GaussianMorphMapBuilder`/`GaussianMorphMapBuilderWindow` (Editor) — blends two `GaussianSplatAsset`s via a precomputed `GaussianMorphMap` correspondence. Not the renderer itself; sits alongside `GaussianSplatRenderer` via external buffer binding. Supports both compressed (chunked) and uncompressed (HighQuality, no chunk data) source assets, in any combination.

**Why**
The correspondence search (nearest-neighbor matching between two splat sets) is computationally expensive — not feasible to run at runtime on Quest. It must be precomputed offline in the editor and baked into a `GaussianMorphMap` asset; runtime only does a cheap per-frame lerp between already-matched pairs. Strict 1:1 uniqueness in that correspondence isn't required; convergence (every splat has a destination to move toward) is the real constraint, so duplicate matches are acceptable when a clean 1:1 match can't be found within the round cap.

The morph's output position/scale buffers are always written in a fixed packed layout (Norm11 position, rot+Norm6-padded scale) by the compute shader, independent of the source assets' import formats — this lets the morph blend any combination of compressed and uncompressed source assets without per-format kernel variants, at the cost of always declaring a distinct "morph output format" to the renderer rather than passing a source asset's format through unmodified.

**Where**
- `Runtime/GaussianSplatting/Morph/GaussianSplatMorpher.cs` — runtime blend driver, GPU buffer upload/output, `t` interpolation. `BindBuffersForT`'s blend branch declares the output format explicitly (`Norm11` pos | `Norm6Padded`(=4, not a `GaussianSplatAsset.VectorFormat` enum value) scale | passthrough SH) rather than reusing source asset format bits. `AllocateOutputBuffers` allocates `m_BufOutPos`/`m_BufOutOther` at fixed strides (4 / 8 bytes) matching that output layout, not derived from source asset strides. `AccumulateAssetBounds` falls back to `asset.boundsMin/boundsMax` when an asset has no chunk data (uncompressed case) instead of skipping that asset's bounds contribution. `DispatchMorph` always binds `_ChunksA`/`_ChunksB` (falling back to the position buffer as a dummy) even when there's no real chunk buffer, since Unity's compute shader validation requires every declared shader resource to be bound regardless of whether the kernel's runtime branch reads it.
- `Editor/GaussianSplatting/Morph/GaussianSplatMorpherEditor.cs` — inspector; has a "Build Morph Map…" button next to asset fields, disabled until both assets are set.
- `Editor/GaussianSplatting/Morph/GaussianMorphMapBuilder.cs` — correspondence search (round-based one-to-one matching + GPU-dispatched remainder resolution), CPU decode helpers.
- `Editor/GaussianSplatting/Morph/GaussianMorphMapBuilderWindow.cs` — editor window UI; `Open(left, right)` overload pre-populates fields.
- `Shaders/SplatCorrespondence.compute` — GPU nearest-neighbor distance search kernel (`FindBestMatch`), reused for both the main round loop and remainder resolution.
- `Shaders/SplatMorph.compute` — per-pair lerp kernel. `OUT_OTHER_STRIDE` (=8) is the fixed per-splat byte stride for the output `Other` buffer (4 rot + 4 Norm6-padded scale), independent of source format. Position is always written via `EncodeNorm11`.
- `Shaders/GaussianSplatting.hlsl` — `VECTOR_FMT_6_PADDED` (=4) is a morph-output-only format constant (never a real serialized asset format) signaling Norm6 bit layout written at a 4-byte-aligned stride instead of the tightly-packed 2-byte stride real `Norm6` assets use.
- `Runtime/GaussianSplatting/GaussianSplatRenderer.cs` — `SetExternalBuffers`'s chunk-buffer swap guard (`if (m_GpuChunks != chunks || m_GpuChunks == null)`) must trigger dummy-buffer creation even when both the incoming `chunks` parameter and the current `m_GpuChunks` are null — a `null != null` reference-equality check alone misses this case, leaving `m_GpuChunks` permanently null.

**When**
- 2026-06-19: Added inspector button to open Morph Map Builder pre-filled with morpher's assets (second creation path, converges into existing build flow). - 2026-06-22: Fixed five chained bugs preventing uncompressed (HighQuality, no chunk data) source assets from working in `GaussianSplatMorpher` — all stemmed from code paths that either (a) skip binding a GPU resource entirely when the source has no chunk data, tripping null-reference or "property not set" failures, or (b) pass a source asset's original format/stride through to describe the morph's actual output buffers, which are always written in a fixed packed layout regardless of source format. Fixed: `SetExternalBuffers`'s null-vs-null chunk-swap guard; `AccumulateAssetBounds`'s skip-when-no-chunk-data (now falls back to asset-level bounds); the output position format passthrough (now explicitly `Norm11`); the output scale format/stride passthrough (now a fixed 8-byte layout with a new `VECTOR_FMT_6_PADDED` HLSL constant); and `DispatchMorph`'s conditional chunk-buffer binding (now always binds, falling back to the position buffer as a dummy).
